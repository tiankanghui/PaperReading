# 一句话理解

用一个具体问题引出论文贡献。注明阅读范围及尚未核查的部分。

## 1. Motivation：为什么需要解决这个问题

说明已有方法的缺口，用论文中的具体例子解释。

## 2. Insight：最值得记住的想法

解释为什么这个设计能够回应上述问题，区分原文判断与个人理解。

## 3. Method：方法如何工作

按输入、处理、输出组织。可插入已核实的论文原图：

```text
![图意概括。来源：原论文 Figure X，PDF 第 X 页。](images/overview.png)
```

图后写“读图要点”，解释应关注的关系。

## 4. Experiments：证据支持了什么

列出数据集、评测协议、关键结果与比较条件。可使用 Markdown 表格；数字须有核实过的原文位置。不要把不同协议的分数当作同一标尺。

## 5. 结论边界与我的判断

哪些结论由实验支持？哪些仍是推测？明确区分。
